# COVID-19 Global Analytics Dashboard | Power BI

An interactive Power BI dashboard developed to analyse key global COVID-19 indicators and present insights through data visualisation and dashboard reporting.

---

## Project Overview

This project uses Power BI to explore worldwide COVID-19 trends, helping users understand the distribution and impact of the pandemic through interactive visualisations and key performance indicators.

The dashboard provides a high-level view of confirmed cases, active cases, recovery rates, death rates, vaccination rates, and country-level comparisons.

---

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Confirmed Cases: 49M
- Recovery Rate: 84.95%
- Death Rate: 1.56%
- Total Active Cases: 7M

### Visualisations Included

- COVID-19 Confirmed Cases Trend
- Global Distribution of Confirmed Cases (Map Visualization)
- Recovery vs Deaths by Country
- Active Cases by Country
- Average Vaccination Rate by Country

---

## Key Analytical Areas

### Trend Analysis
Tracks confirmed COVID-19 cases over time to identify major increases and decreases.

### Geographic Analysis
Displays the distribution of confirmed cases across multiple countries using map-based visualisation.

### Country Comparison
Compares active cases, recoveries, and death counts between countries.

### Vaccination Analysis
Examines average vaccination rates across countries and highlights differences in vaccination coverage.
